## 1. 초기 데이터 탐색(EDA) 및 검증의 위기
**문제 발생:**
초기 원본 데이터(A, B 이미지)를 모델에 바로 주입하려 했으나, 영상이 일반적인 2D가 아닌 `TZYX(LED, Z-layer, Y, X)` 4차원 Hyperstack 구조로 엮여 있었습니다. 더 큰 문제는 중앙부(ROI)의 픽셀 밝기가 한계치(65535)에 도달하는 포화(Saturation) 현상이 최대 50%까지 발생하여, 센서의 한계를 결함으로 잘못 학습할 위험이 컸습니다.

**해결 과정:**
단순히 밝은 곳을 잘라내는(Crop) 것으로는 포화 문제가 해결되지 않음을 확인했습니다. 이에 따라 밝기 정보와 별개로 해당 픽셀이 포화되었는지를 0과 1로 알려주는 **타당성 마스크(Validity Mask) 3채널을 추가**하여, 모델이 총 6-채널(3 Intensity + 3 Mask)을 입력받도록 설계함으로써 센서 아티팩트(Artifact)를 강건하게 처리했습니다.

## 2. 타겟 점수(Target Semantics) 판독 위기
**문제 발생:**
사후 XCT 데이터로부터 0.0 ~ 1.0 사이의 연속적인 품질 점수(Weak Target)를 만들어 냈지만, 이 점수가 물리적으로 '높은 게 결함인지, 낮은 게 결함인지' 방향성이 불분명했습니다.

**해결 과정:**
데이터셋 전체를 스캔해 가장 점수가 높은 픽셀들과 가장 낮은 픽셀들의 원본 패치(32x32 Crop Mosaic)를 추출해 육안 판독(Visual Audit)을 실시했습니다. 그 결과, 점수가 높은 구간에서 쇳물이 튀거나 다크 스팟이 파이는 명확한 결함 패턴이 확인되었습니다. 이를 통해 **"High Score = Defect"**라는 기준을 확립하고, 모델 학습의 목표 방향성(Semantics)을 고정할 수 있었습니다.

## 3. 물리 좌표 캘리브레이션 위기
**문제 발생:**
의료용 CT와 달리 제조 현장에서 촬영되는 AMMT 공정 영상은 노이즈가 극심했습니다. 가장 큰 문제는 모델이 예측한 카메라의 2D 픽셀 좌표를 기계의 3D 물리 좌표계로 변환해야 정답지(XCT)와 비교할 수 있는데, 격자(DotGrid)의 대칭성 때문에 카메라 렌즈의 상하좌우가 뒤집혀도 수학적 오차가 똑같이 나오는 "거울상 모호성(Mirror/Rotation Ambiguity)" 현상이 발생했습니다.

**해결 과정:**
비대칭적 설계 구조(구멍과 돌출부)를 가진 125층(Layer 125)의 원본 이미지 위에 기계 제어 궤적을 겹쳐 그리는 스크립트(`archive/audit_layer125_orientation_overlay.py`)를 개발했습니다. 이를 육안으로 판독하여 `mirror_rotate_270` 캘리브레이션 옵션이 물리적 진실임을 확정 지었습니다.

## 2. 첫 번째 위기: A-only 모델의 '위치 추정 평탄화(Map Invariance)'
**문제 발생:**
초기에는 분말 도포 직후(A) 이미지만을 사용하여 예측을 시도하는 `A-only Baseline` 모델을 구축했습니다. 하지만 모델 학습 결과, 특정 결함 위치를 지목(Localization)하지 못하고 맵 전체가 하나의 동일한 점수로 도배되어 버리는(Top-score tie plateau) 심각한 현상이 발견되었습니다.

**해결 과정:**
진단 스크립트(`diagnose_a_only_input_sensitivity.py`)를 통해 모델 내부를 수학적으로 뜯어본 결과, 입력 데이터가 시간축 압축(Temporal Aggregation) 레이어를 통과하는 순간 모든 정보가 소실되는 'Temporal Collapse' 현상임을 밝혀냈습니다. 이를 해결하기 위해 이전 프레임과 현재 프레임의 '차이(Difference)'에만 집중하도록 구조를 변경한 **시계열 차분(Temporal Difference)** 인코더를 도입하여 평탄화 현상을 극복했습니다.

## 3. 두 번째 위기: 단순 병합(Concat)의 노이즈 간섭
**문제 발생:**
가루(A) 모델에 더해, 가장 강력한 열적 신호(스패터 등)를 포함하는 쇳물(B) 데이터를 결합하기 위해, A와 B의 특징을 단순히 이어붙이는 `A+B Concat Fusion` 모델을 설계했습니다. 그러나 기대와 달리 융합 모델의 테스트 오차(0.0550)가 B-only 단독 모델(0.0546)보다 떨어지는 현상이 발생했습니다.

**해결 과정:**
원인을 분석해 보니, 결함 신호가 강력한 B 이미지 정보를 A 이미지의 무작위 노이즈가 깎아내리면서 디코더를 혼란스럽게 만드는 '노이즈 간섭'이 원인이었습니다. 이를 해결하기 위해, 모델이 스스로 정보의 중요도를 채널 및 공간별로 판단하여(Attention) 쓸모없는 노이즈 밸브를 차단하는 **Gated CNN Fusion** 아키텍처를 새롭게 고안했습니다.

---

## 4. 세 번째 위기: 모델 용량 증가와 과적합(Overfitting)
**문제 발생:**
Gated Fusion 모델(v2)로 훈련한 결과, 검증 오차(Validation Loss)를 무려 0.0302까지 획기적으로 떨어뜨렸으며, 평탄화 현상 없이 테스트 이미지 48개에서 모두 고유한 위치를 추정해 내는 데 성공했습니다. 하지만 치명적이게도 미지의 데이터인 Test Loss는 0.0596으로 상승해 버렸습니다.

**해결 과정 (현재 상황):**
강력한 Gate 모듈 탓에 모델이 훈련 데이터 내의 자잘한 카메라 노이즈까지 완벽하게 외워버리는 전형적인 과적합(Overfitting)에 빠졌음을 진단했습니다. 이를 방어하기 위해 다음과 같은 강력한 정규화(Regularization) 조치를 취한 `v3` 모델을 구현했습니다.
1. **Spatial Dropout (30%):** 디코더 계층 사이에 정보 흐름을 무작위로 30%씩 끊어내어 특정 특징에 과도하게 의존하는 것을 방지.
2. **AdamW Weight Decay 상향:** 가중치 감쇠량을 기존 `1e-5`에서 `1e-2`로 1000배 끌어올려 비대해진 모델 가중치를 강제로 깎아냄.

**결과 및 의의:**
v3 모델의 평가 결과, 미지의 Test Loss를 기존 0.0596에서 0.0561로 크게 낮추는 데 성공했습니다. 하지만 여전히 B-only 단일 모델(0.0546)의 벽을 넘지는 못했습니다.
이를 완전히 돌파하기 위해 추가적으로 **'물리적 다이어트(Capacity Reduction)'** 전략을 적용한 `v4` 모델을 설계했습니다. 모델의 두뇌 용량을 결정하는 `base_channels`를 32에서 16으로 반토막 내어 꼼수를 부릴 여지를 원천 차단했습니다.

그 결과, v4 모델은 Validation Loss 0.0306을 기록하며, **최종 Test Loss를 0.0531까지 끌어내려 드디어 역사적인 B-only 베이스라인(0.0546) 격파에 성공했습니다!** 동시에 48개의 테스트 이미지에서 모두 고유한 이상 후보 위치를 단 하나도 놓치지 않고 완벽하게 잡아냈습니다(`emitted: 48`). 
이로써 '단순 병합의 노이즈 간섭'과 '융합 모델의 과적합'이라는 딜레마를 완전히 극복하고, 가루(A)와 쇳물(B) 정보를 모두 활용하는 최강의 이상 탐지 융합 아키텍처 구축을 완수했습니다.
