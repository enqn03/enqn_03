## 2. 현재 확정된 입력 정책

`configs/normalization_v1.yaml`은 A/B·LED별 train-only robust normalization을 정의한다. `configs/calibration_v1.yaml`은 provisional rank2 `mirror_rotate_270` camera projection과 `(0,-6)` raw-pixel correction을 정의한다. `configs/weak_target_v1.yaml`은 registered command XY(열 3–4), response `xct_5x5x5`(열 40), train-only p01=0.40070/p99=0.58533 robust scaling, sigma=2 model pixel, unknown support policy를 고정한다. 모델 입력은 `[K,6,H,W]`이며 3 intensity channel과 3 validity-mask channel으로 구성된다. weak target은 direction-unresolved continuous XCT-derived quality response이고 support 밖은 unknown이다.

## 3. Weak target Dataset 연결 및 검증 완료

**코드 위치:** `src/ammt_weak_target_dataset.py`이며 프로젝트 root `~/ammt_project`에서 실행한다. 이 wrapper는 원본 TIFF를 `memmap`으로 읽고, manifest의 endpoint `z`에 해당하는 registered XCT CSV만 읽어 command XY를 raw camera pixel로 투영한다. working ROI와 256×256 model grid에 맞춰 sigma=2 Gaussian weighted response를 메모리에서 생성하고, dense target 파일은 저장하지 않는다.

| 검증 sample | 실행 인덱스·endpoint | 확인 결과 | 의미 |
|---|---|---|---|
| early unavailable | `train --index 0`, z=4 | support fraction=0.0, supervised pixel=0, available=false | early XCT 부재가 normal/zero target이 아니라 **unknown·loss 제외**로 처리됨 |
| available support | `train --index 124`, z=128 | input `[4,6,256,256]`, target `[1,256,256]`, support fraction=0.05247498, supervised pixel=3,439, supported response range `[0.0, 0.85119]`, available=true | command-XY calibrated projection과 train-only robust scaling이 실제 target sample에서 동작함 |

**실행 전 상태:** raw TIFF/CSV는 불변이고 `processed/`에 dense target이 없다. **실행 후 상태:** 메모리 sample dictionary에 다음 항목만 추가된다.

| key | shape·type | 역할 |
|---|---|---|
| `weak_response` | `[1,256,256]`, float | clipped train-p01/p99 scaled continuous XCT-derived response |
| `weak_support_mask` | `[1,256,256]`, float 0/1 | supervised pixel=1, unknown=0 |
| `weak_target_available` | scalar bool | endpoint layer에 하나 이상의 camera-ROI support가 존재하는지 표시 |
| `weak_supervised_pixel_count` | scalar int64 | support-mask weighted loss에 사용할 valid target pixel 수 |

## 4. Support-mask weighted continuous regression loss

**코드 위치:** `src/ammt_masked_regression_loss.py`이며, 학습 코드가 model의 `[batch,1,256,256]` candidate-response prediction을 만들면 이 모듈에 전달한다. `configs/masked_regression_loss_v1.yaml`은 Smooth L1의 `beta=0.1`, global supported-pixel mean reduction, unknown handling을 고정한다.

> **수식:** `L = Σ_i m_i · SmoothL1(p_i, y_i) / Σ_i m_i`이다. `p`는 model의 `[0,1]` continuous response prediction, `y`는 `weak_response`, `m`은 `weak_support_mask`다. `Σ_i m_i=0`인 batch는 loss=0으로 반환한다.

`SmoothL1`은 일반적인 squared error보다 sparse XCT response의 국소적 정합 오차와 outlier에 덜 민감하다. 이 loss는 defect classifier loss가 아니며, response direction이 unresolved인 현 상태에서 “XCT-derived continuous quality response를 잘 재현하는가”만 학습한다.

### Read-only 검증 명령

프로젝트 root에서 아래 명령을 실행한다. 이 검증은 model training이 아니며, TIFF/CSV를 읽기 전용으로 사용하고 terminal JSON 외의 파일을 만들지 않는다.

```bash
cd ~/ammt_project
/usr/local/bin/python3 src/verify_masked_regression_loss.py \
  --stage A \
  --tiff raw_original/layer_camera/LayerCameraAfterSpreading.tif \
  --manifest manifests/causal_sequence_manifest.csv \
  --normalization-config configs/normalization_v1.yaml \
  --registered-root raw_original/registered_xct \
  --calibration-config configs/calibration_v1.yaml \
  --weak-target-config configs/weak_target_v1.yaml \
  --loss-config configs/masked_regression_loss_v1.yaml \
  --split train \
  --unavailable-index 0 \
  --available-index 124
```

| 검증 항목 | 통과 조건 | 실제 결과 | 확인하는 위험 |
|---|---|---|---|
| z=4 unknown | `loss=0`, supervised pixel=0, 모든 gradient sum=0 | **통과:** loss=0.0, supported/unsupported gradient sum=0.0 | XCT 미지원 layer를 normal target으로 학습하는 오류 |
| z=128 supported response | positive loss, supported gradient sum>0 | **통과:** 3,439 pixel, baseline loss=0.60062975, supported gradient=0.99932176 | sparse supervised point에서만 regression 신호가 생기는지 |
| unknown prediction 불변성 | unknown pixel prediction을 1000으로 바꿔도 loss difference≤`1e-8` | **통과:** loss difference=0.0 | support 밖 pixel이 학습 loss에 새는 오류 |
| unknown gradient 차단 | unsupported gradient sum=0 | **통과:** unsupported gradient sum=0.0 | target이 없는 camera pixel이 training update를 유발하는 오류 |

## 5. 다음 실행 순서

1. **완료:** runtime 검증에서 `overall_pass: true`를 확인했다.
2. A-only baseline은 raw candidate logits에 `sigmoid`를 적용해 `[0,1]` prediction을 만든 뒤 이 masked loss에 전달한다.
3. train/validation/test masked loss를 support가 있는 pixel에 한정해 기록한다.
4. output은 방향 검증 전까지 `XCT-derived quality candidate`로 표현한다.
5. XCT segmentation 또는 수동 검토로 high/low response의 물리적 anomaly direction을 검증한 뒤에만 anomaly likelihood나 binary threshold를 정의한다.

## 6. 실행 원칙

* `processed/`는 재생성 가능한 결과이며 기본적으로 Git 추적 대상이 아니다. 다만 검토 근거를 보존하기 위해 11개 QC PNG 사본과 설명은 `docs/qc_images/`, `docs/quality-control-images.md`에 Git 추적한다.
* full-scale saturation `raw==65535`은 validity mask=0이다.
* target support 밖과 early XCT 미지원 layer는 negative/normal이 아니라 unknown이다.
* validation/test는 normalization·target scaling 통계에 사용하지 않는다.
* 새 코드가 추가되면 이 표에 실행 위치, 역할, 입력, 출력, 의존성을 추가한다.
