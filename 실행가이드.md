## 2. 현재 확정된 입력 정책

`configs/normalization_v1.yaml`은 A/B·LED별 train-only robust normalization을 정의한다. `configs/calibration_v1.yaml`은 provisional rank2 `mirror_rotate_270` camera projection과 `(0,-6)` raw-pixel correction을 정의한다. `configs/weak_target_v1.yaml`은 registered command XY(열 3–4), response `xct_5x5x5`(열 40), train-only p01=0.40070/p99=0.58533 robust scaling, sigma=2 model pixel, unknown support policy를 고정한다. 모델 입력은 `[K,6,H,W]`이며 3 intensity channel과 3 validity-mask channel으로 구성된다. weak target은 direction-unresolved continuous XCT-derived quality response이고 support 밖은 unknown이다.

## 3. Weak target Dataset 연결 및 검증 완료

**코드 위치:** `src/ammt_weak_target_dataset.py`이며 프로젝트 root `~/ammt_project`에서 실행한다. 이 wrapper는 원본 TIFF를 `memmap`으로 읽고, manifest의 endpoint `z`에 해당하는 registered XCT CSV만 읽어 command XY를 raw camera pixel로 투영한다. working ROI와 256×256 model grid에 맞춰 sigma=2 Gaussian weighted response를 메모리에서 생성하고, dense target 파일은 저장하지 않는다.

## 4. Support-mask weighted continuous regression loss

**코드 위치:** `src/ammt_masked_regression_loss.py`이며, 학습 코드가 model의 `[batch,1,256,256]` candidate-response prediction을 만들면 이 모듈에 전달한다. `configs/masked_regression_loss_v1.yaml`은 Smooth L1의 `beta=0.1`, global supported-pixel mean reduction, unknown handling을 고정한다.

> **수식:** `L = Σ_i m_i · SmoothL1(p_i, y_i) / Σ_i m_i`이다. `p`는 model의 `[0,1]` continuous response prediction, `y`는 `weak_response`, `m`은 `weak_support_mask`다. `Σ_i m_i=0`인 batch는 loss=0으로 반환한다.

`SmoothL1`은 일반적인 squared error보다 sparse XCT response의 국소적 정합 오차와 outlier에 덜 민감하다. 이 loss는 defect classifier loss가 아니며, response direction이 unresolved인 현 상태에서 “XCT-derived continuous quality response를 잘 재현하는가”만 학습한다.

## 5. A-only baseline

**코드 위치:** `src/train_a_only_baseline.py`이며 project root `~/ammt_project`에서 실행한다. `configs/a_only_baseline_v1.yaml`은 A-stage, K=4, six-channel input, base channels=8, causal past-padded Conv3D aggregation, sigmoid output, AdamW, 8 epochs를 고정한다. 이 모델은 기존 3-channel skeleton을 그대로 쓰지 않고 **3 intensity+3 validity-mask의 6채널 contract**를 직접 소비한다.

입력은 `[B,4,6,256,256]`이고 output은 `[B,1,256,256]`이다. raw candidate logits에는 sigmoid를 적용해 `[0,1]` continuous response prediction을 만들며, `SupportMaskedSmoothL1Loss`가 `weak_support_mask==1` pixel에서만 regression을 계산한다. causal temporal convolution은 왼쪽(past) 방향에만 padding하므로 future layer를 참조하지 않는다.

## 6. 다음 실행 순서

1. **완료:** A-only dry-run에서 input `[1,4,6,256,256]`, prediction `[1,1,256,256]`, z=128 support 3,439 pixel, finite loss=0.11099906, device=`mps`를 확인했다. 무작위 초기 model의 output이 약 0.518로 spatially constant인 것은 아직 학습 전이므로 정상이다.
2. A-only baseline 학습에서 validation supported-pixel mean Smooth L1 checkpoint를 선택한다.
3. **run 1 결과:** epoch 8 best validation masked loss=0.06163210, held-out test loss=0.07344962. Training plumbing과 supported-pixel regression은 동작했지만 test loss는 validation보다 19.17% 높다.
4. **localization hold:** 현재 `test_coordinate_candidates.json`은 48 endpoint×top-5=240개 record 중 score가 한 값(0.67868608)으로, model-space coordinate도 5개 위치가 모든 endpoint에 반복된다. 이는 flat output plateau에서 발생한 임의 top-k tie이므로 실제 품질 후보 위치로 사용하지 않는다.
5. **실행 완료:** test z=203/227/250에서 global map range=0.67868543, std=0.11746240이지만 support 내부 prediction std=0.0·Pearson=null인 고정 plateau를 확인했다. 기존 global range gate는 `emitted`를 반환했으므로 coordinate를 물리 후보로 사용하지 않는다.
6. **실행 완료:** z=203/z=227/z=250 각각에서 top-score tie=63,504 pixel=96.8994%, z=203→227 및 z=227→250 map MAE/max-absolute=0.0을 확인했다. 세 endpoint 모두 `withheld_top_score_plateau`, candidate count=0으로 안전하게 보류됐다.
7. `top_score_tie_fraction > 0.001`이면 `withheld_top_score_plateau`, 연속 endpoint map의 MAE와 max-absolute difference가 모두 `≤1e-6`이면 `withheld_temporally_invariant_map`을 반환한다. 적용 순서는 full-map flat → top-score tie plateau → temporal invariance → local-maximum emission이다. 이 값은 **support mask 없이** model prediction map만 사용한다.
8. **E24 held-out 완료:** best validation epoch=9, masked loss=0.06152481로 run 1보다 0.17% 낮았으나 held-out test loss=0.07370871로 run 1보다 0.35% 높았다. epoch 10–24 validation은 다시 상승/정체했으므로 training duration은 localization 해결 축으로 지지되지 않는다.
9. e24 test candidate loop에 있던 `sample=dataset[index]` 누락은 복구했고, checkpoint-only evaluator가 test JSON을 생성했다. E24는 48/48 endpoint에서 `withheld_top_score_plateau`, candidate=0이었다.
10. E24에서도 top-score tie fraction=96.8994%, selected endpoint map MAE/max-absolute=0/0, support-region prediction std=0으로 run 1과 같은 input-invariant plateau가 유지됐다.
11. C32 run은 epoch=8, model `base_channels=32`로 실행 완료됐다. Run 1과 비교해 top-score tie fraction은 96.8994%→0.3845%로 줄었지만, held-out test loss는 0.24% 높고 selected endpoint map MAE/max-absolute=0/0과 support prediction std=0이 유지됐다.
12. 따라서 capacity는 global static geometry를 바꾸었으나 input-dependent localization을 복원하지 못했다. C32에서도 48/48 endpoint는 `withheld_top_score_plateau`, candidate=0으로 안전하게 보류됐다.
13. 다음 단일 검증은 target rasterization의 Gaussian sigma만 2→3으로 바꾸는 read-only support-density audit이다. raw input/CSV/calibration/response scaling 및 unknown policy를 고정하고 coverage와 blur trade-off를 확인한다.
14. output은 direction 검증 전까지 `XCT-derived quality candidate`로 표현한다.
15. XCT segmentation 또는 수동 검토로 high/low response의 물리적 anomaly direction을 검증한 뒤에만 anomaly likelihood나 binary threshold를 정의한다.

**코드 위치:** `src/diagnose_a_only_input_sensitivity.py`이며 project root에서 실행한다. 이 코드는 target/label diagnostic이 아니라 checkpoint 내부의 A input response 추적용이다. `AMMTCausalStageDataset`만 사용하므로 registered XCT CSV, weak target, support mask, masked loss, candidate decoder에 접근하지 않는다.

입력은 C32 config/checkpoint, A-stage TIFF, causal manifest, train-only normalization config다. | Stage | 실제 측정 | pairwise max-abs가 `>1e-6`일 때의 의미 |
|---|---|---|
| `input_history` | selected A history의 6-channel tensor | Dataset input이 실제로 다름 |

| `score` | sigmoid final map | activation 이후에도 numeric difference 유지 |

모든 pair가 특정 stage에서 `≤1e-6`이면 그 stage가 collapse-origin 후보가 된다. 예를 들어 encoder history는 다르지만 temporal final부터 같으면 temporal aggregation/normalization이 후보이고, logits는 다른데 score만 같으면 sigmoid saturation 후보이다. 이 판정은 **수치적 difference 여부**만 보여 준다. score map이 다르더라도 XCT localization 품질이나 candidate deployment readiness가 자동으로 보장되지는 않는다.

| Stage | z203↔227 | z203↔250 | z227↔250 | 해석 |
|---|---:|---:|---:|---|
| `input_history` max-abs | 1.0 | 1.0 | 1.0 | 세 causal A input은 구별됨 |
| `encoded_final_history_frame` max-abs | 2.295962 | 2.033926 | 1.931690 | endpoint frame encoder feature는 구별됨 |
| `encoded_history` max-abs | 2.478056 | 2.153886 | 2.508519 | 4-step encoder feature sequence도 구별됨 |
| `temporal_final` MAE / max-abs | 0 / 0 | 0 / 0 | 0 / 0 | **variation이 이 stage에서 처음 소실** |
| `logits`, `score` MAE / max-abs | 0 / 0 | 0 / 0 | 0 / 0 | temporal collapse가 output까지 전달됨 |

Self-consistency check의 `forward_reconstruction_max_abs=0`으로 exposed diagnostic path가 ordinary `model.forward()` output과 일치했다. 따라서 C32 current checkpoint에 대해 frame encoder와 sigmoid가 아니라 `Conv3D → GroupNorm → SiLU` temporal path가 selected input variation을 잃는 직접 관찰 근거가 확보됐다. 이 결과는 causal temporal module 전체가 일반적으로 잘못됐다는 선언이 아니라, **이 architecture/checkpoint/input에서만** 다음 변경 대상을 temporal path로 좁힌다.

다음 single controlled experiment은 optional endpoint-feature residual bypass다. Concept은 `temporal_final = encoded_endpoint + temporal_update`이며 current endpoint A feature와 past-only temporal update만 사용하므로 future layer leakage가 없다. 기존 C8/E24/C32 config에는 flag가 없으므로 default `false`로 former architecture와 checkpoint state-dict compatibility를 보존한다.
