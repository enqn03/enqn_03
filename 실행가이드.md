## 2. 현재 확정된 입력 정책

`configs/normalization_v1.yaml`은 A/B·LED별 train-only robust normalization을 정의한다. `configs/calibration_v1.yaml`은 provisional rank2 `mirror_rotate_270` camera projection과 `(0,-6)` raw-pixel correction을 정의한다. `configs/weak_target_v1.yaml`은 registered command XY(열 3–4), response `xct_5x5x5`(열 40), train-only p01=0.40070/p99=0.58533 robust scaling, sigma=2 model pixel, unknown support policy를 고정한다. 모델 입력은 `[K,6,H,W]`이며 3 intensity channel과 3 validity-mask channel으로 구성된다. weak target은 direction-unresolved continuous XCT-derived quality response이고 support 밖은 unknown이다.

## 3. Weak target Dataset 연결 및 검증 완료

**코드 위치:** `src/ammt_weak_target_dataset.py`이며 프로젝트 root `~/ammt_project`에서 실행한다. 이 wrapper는 원본 TIFF를 `memmap`으로 읽고, manifest의 endpoint `z`에 해당하는 registered XCT CSV만 읽어 command XY를 raw camera pixel로 투영한다. working ROI와 256×256 model grid에 맞춰 sigma=2 Gaussian weighted response를 메모리에서 생성하고, dense target 파일은 저장하지 않는다.

| 검증 sample | 실행 인덱스·endpoint | 확인 결과 | 의미 |
|---|---|---|---|
| early unavailable | `train --index 0`, z=4 | support fraction=0.0, supervised pixel=0, available=false | early XCT 부재가 normal/zero target이 아니라 **unknown·loss 제외**로 처리됨 |
| available support | `train --index 124`, z=128 | input `[4,6,256,256]`, target `[1,256,256]`, support fraction=0.05247498, supervised pixel=3,439, supported response range `[0.0, 0.85119]`, available=true | command-XY calibrated projection과 train-only robust scaling이 실제 target sample에서 동작함 |

**실행 전 상태:** raw TIFF/CSV는 불변이고 `processed/`에 dense target이 없다. **실행 후 상태:** 메모리 sample dictionary에 다음 항목만 추가된다.

| key | shape·type | 역할 |
|---|---|---|
| `weak_response` | `[1,256,256]`, float | clipped train-p01/p99 scaled continuous XCT-derived response |
| `weak_support_mask` | `[1,256,256]`, float 0/1 | supervised pixel=1, unknown=0 |
| `weak_target_available` | scalar bool | endpoint layer에 하나 이상의 camera-ROI support가 존재하는지 표시 |
| `weak_supervised_pixel_count` | scalar int64 | support-mask weighted loss에 사용할 valid target pixel 수 |

## 4. Support-mask weighted continuous regression loss

**코드 위치:** `src/ammt_masked_regression_loss.py`이며, 학습 코드가 model의 `[batch,1,256,256]` candidate-response prediction을 만들면 이 모듈에 전달한다. `configs/masked_regression_loss_v1.yaml`은 Smooth L1의 `beta=0.1`, global supported-pixel mean reduction, unknown handling을 고정한다.

> **수식:** `L = Σ_i m_i · SmoothL1(p_i, y_i) / Σ_i m_i`이다. `p`는 model의 `[0,1]` continuous response prediction, `y`는 `weak_response`, `m`은 `weak_support_mask`다. `Σ_i m_i=0`인 batch는 loss=0으로 반환한다.

`SmoothL1`은 일반적인 squared error보다 sparse XCT response의 국소적 정합 오차와 outlier에 덜 민감하다. 이 loss는 defect classifier loss가 아니며, response direction이 unresolved인 현 상태에서 “XCT-derived continuous quality response를 잘 재현하는가”만 학습한다.

### Read-only 검증 명령

프로젝트 root에서 아래 명령을 실행한다. 이 검증은 model training이 아니며, TIFF/CSV를 읽기 전용으로 사용하고 terminal JSON 외의 파일을 만들지 않는다.

```bash
cd ~/ammt_project
/usr/local/bin/python3 src/verify_masked_regression_loss.py \
  --stage A \
  --tiff raw_original/layer_camera/LayerCameraAfterSpreading.tif \
  --manifest manifests/causal_sequence_manifest.csv \
  --normalization-config configs/normalization_v1.yaml \
  --registered-root raw_original/registered_xct \
  --calibration-config configs/calibration_v1.yaml \
  --weak-target-config configs/weak_target_v1.yaml \
  --loss-config configs/masked_regression_loss_v1.yaml \
  --split train \
  --unavailable-index 0 \
  --available-index 124
```

| 검증 항목 | 통과 조건 | 실제 결과 | 확인하는 위험 |
|---|---|---|---|
| z=4 unknown | `loss=0`, supervised pixel=0, 모든 gradient sum=0 | **통과:** loss=0.0, supported/unsupported gradient sum=0.0 | XCT 미지원 layer를 normal target으로 학습하는 오류 |
| z=128 supported response | positive loss, supported gradient sum>0 | **통과:** 3,439 pixel, baseline loss=0.60062975, supported gradient=0.99932176 | sparse supervised point에서만 regression 신호가 생기는지 |
| unknown prediction 불변성 | unknown pixel prediction을 1000으로 바꿔도 loss difference≤`1e-8` | **통과:** loss difference=0.0 | support 밖 pixel이 학습 loss에 새는 오류 |
| unknown gradient 차단 | unsupported gradient sum=0 | **통과:** unsupported gradient sum=0.0 | target이 없는 camera pixel이 training update를 유발하는 오류 |

## 5. A-only baseline

**코드 위치:** `src/train_a_only_baseline.py`이며 project root `~/ammt_project`에서 실행한다. `configs/a_only_baseline_v1.yaml`은 A-stage, K=4, six-channel input, base channels=8, causal past-padded Conv3D aggregation, sigmoid output, AdamW, 8 epochs를 고정한다. 이 모델은 기존 3-channel skeleton을 그대로 쓰지 않고 **3 intensity+3 validity-mask의 6채널 contract**를 직접 소비한다.

입력은 `[B,4,6,256,256]`이고 output은 `[B,1,256,256]`이다. raw candidate logits에는 sigmoid를 적용해 `[0,1]` continuous response prediction을 만들며, `SupportMaskedSmoothL1Loss`가 `weak_support_mask==1` pixel에서만 regression을 계산한다. causal temporal convolution은 왼쪽(past) 방향에만 padding하므로 future layer를 참조하지 않는다.

### 5.1 Read-only dry-run

dry-run은 무작위 초기화 model이 shape·range·loss contract에 맞게 forward되는지만 확인한다. 학습, optimizer step, checkpoint, heatmap, output file 생성이 전혀 없다.

```bash
cd ~/ammt_project
/usr/local/bin/python3 src/train_a_only_baseline.py \
  --config configs/a_only_baseline_v1.yaml \
  --tiff-a raw_original/layer_camera/LayerCameraAfterSpreading.tif \
  --manifest manifests/causal_sequence_manifest.csv \
  --normalization-config configs/normalization_v1.yaml \
  --registered-root raw_original/registered_xct \
  --calibration-config configs/calibration_v1.yaml \
  --weak-target-config configs/weak_target_v1.yaml \
  --loss-config configs/masked_regression_loss_v1.yaml \
  --dry-run \
  --dry-run-index 124
```

| dry-run 확인 항목 | 기대 조건 |
|---|---|
| input shape | `[1,4,6,256,256]` |
| prediction shape | `[1,1,256,256]` |
| prediction range | sigmoid 때문에 0 이상 1 이하 |
| endpoint | index 124이므로 z=128 |
| target support | supervised pixel count=3,439 |
| masked loss | **통과:** 0.11099906. 양수 finite 값이며, 무작위 초기 model의 성능 수치가 아님 |
| device | **통과:** Apple `mps`에서 forward·masked loss 계산 성공 |

### 5.2 실제 baseline 학습

dry-run 통과 후 아래 명령을 실행한다. **실행 전 상태:** raw TIFF/CSV는 읽기 전용이며 `outputs/a_only_baseline_v1/`이 없어야 한다. 기존 output을 덮어쓰지 않도록 directory가 이미 있으면 script가 중단한다. 재실행은 검토 후 새 `--output-dir` 이름을 사용한다.

```bash
cd ~/ammt_project
/usr/local/bin/python3 src/train_a_only_baseline.py \
  --config configs/a_only_baseline_v1.yaml \
  --tiff-a raw_original/layer_camera/LayerCameraAfterSpreading.tif \
  --manifest manifests/causal_sequence_manifest.csv \
  --normalization-config configs/normalization_v1.yaml \
  --registered-root raw_original/registered_xct \
  --calibration-config configs/calibration_v1.yaml \
  --weak-target-config configs/weak_target_v1.yaml \
  --loss-config configs/masked_regression_loss_v1.yaml \
  --output-dir outputs/a_only_baseline_v1
```

| 학습 후 생성 파일 | 내용 | Git 정책 |
|---|---|---|
| `best_validation_supported_loss.pt` | validation supported-pixel mean Smooth L1가 가장 낮은 epoch의 small checkpoint | `outputs/` 제외 |
| `training_history.json` | epoch별 train/validation masked loss·support pixel/sample count·optimizer step 수 | `outputs/` 제외 |
| `test_metrics.json` | best checkpoint의 held-out causal test supported-pixel metric | `outputs/` 제외 |
| `test_coordinate_candidates.json` | test endpoint마다 top-5 local-maximum `(x_pixel,y_pixel,layer_z,score)` 후보 | `outputs/` 제외 |

candidate JSON은 dense heatmap을 저장하지 않는다. `score`는 sigmoid-scaled **XCT-derived continuous quality candidate**이며, response direction이 unresolved이므로 anomaly probability, defect class, pass/fail score로 해석하지 않는다.

## 6. 다음 실행 순서

1. **완료:** A-only dry-run에서 input `[1,4,6,256,256]`, prediction `[1,1,256,256]`, z=128 support 3,439 pixel, finite loss=0.11099906, device=`mps`를 확인했다. 무작위 초기 model의 output이 약 0.518로 spatially constant인 것은 아직 학습 전이므로 정상이다.
2. A-only baseline 학습에서 validation supported-pixel mean Smooth L1 checkpoint를 선택한다.
3. **run 1 결과:** epoch 8 best validation masked loss=0.06163210, held-out test loss=0.07344962. Training plumbing과 supported-pixel regression은 동작했지만 test loss는 validation보다 19.17% 높다.
4. **localization hold:** 현재 `test_coordinate_candidates.json`은 48 endpoint×top-5=240개 record 중 score가 한 값(0.67868608)으로, model-space coordinate도 5개 위치가 모든 endpoint에 반복된다. 이는 flat output plateau에서 발생한 임의 top-k tie이므로 실제 품질 후보 위치로 사용하지 않는다.
5. **실행 완료:** test z=203/227/250에서 global map range=0.67868543, std=0.11746240이지만 support 내부 prediction std=0.0·Pearson=null인 고정 plateau를 확인했다. 기존 global range gate는 `emitted`를 반환했으므로 coordinate를 물리 후보로 사용하지 않는다.
6. **구현 완료·사용자 실행 대기:** decoder diagnostic은 상위-score 동점 pixel 수/면적 비율과 selected endpoint 간 prediction MAE·max-absolute difference를 출력한다. 이 값은 **support mask 없이** model prediction map만 사용한다.
7. `top_score_tie_fraction > 0.001`이면 `withheld_top_score_plateau`, 연속 선택 endpoint map의 MAE와 max-absolute difference가 모두 `≤1e-6`이면 `withheld_temporally_invariant_map`을 반환한다. 적용 순서는 full-map flat → top-score tie plateau → temporal invariance → local-maximum emission이다.
8. output은 direction 검증 전까지 `XCT-derived quality candidate`로 표현한다.
9. XCT segmentation 또는 수동 검토로 high/low response의 물리적 anomaly direction을 검증한 뒤에만 anomaly likelihood나 binary threshold를 정의한다.

### 6.1 Spatial diagnostic 실행

**코드 위치:** `src/diagnose_a_only_spatial_predictions.py`이며 project root에서 실행한다. checkpoint와 원본 input/target source를 읽기 전용으로 사용해 selected endpoint의 prediction spatial variation, support 내 target variation, Pearson correlation, plateau-safe decoder status를 terminal JSON으로 출력한다. model update, checkpoint 변경, dense heatmap/crop/target/result file 생성은 없다. Decoder 통합 중 발견된 `history` input-assign SyntaxError는 checkpoint/TIFF/XCT 접근 전에 복구됐으며, 재실행으로 import·data-flow를 확인한다.

```bash
cd ~/ammt_project
/usr/local/bin/python3 src/diagnose_a_only_spatial_predictions.py \
  --config configs/a_only_baseline_v1.yaml \
  --checkpoint outputs/a_only_baseline_v1/best_validation_supported_loss.pt \
  --tiff-a raw_original/layer_camera/LayerCameraAfterSpreading.tif \
  --manifest manifests/causal_sequence_manifest.csv \
  --normalization-config configs/normalization_v1.yaml \
  --registered-root raw_original/registered_xct \
  --calibration-config configs/calibration_v1.yaml \
  --weak-target-config configs/weak_target_v1.yaml \
  --split test \
  --indices 0 24 47
```

| diagnostic 출력 | 해석 |
|---|---|
| `prediction_statistics.spatial_range`, `std_population` | **관측:** global range=0.67868543, std=0.11746240. 전역 map은 constant가 아님 |
| `supported_prediction_statistics` | **관측:** 세 test endpoint에서 min=max=0.67868608, std=0.0. supervised region은 완전히 평탄 |
| `supported_target_statistics` | **관측:** target std=0.13695–0.15744로 non-flat. target이 아니라 model variation이 병목 |
| `prediction_target_pearson_on_support` | **관측:** `null`. supported prediction variance=0이므로 상관이 정의되지 않음 |
| `flat_by_spatial_range_atol` | **관측:** `false`. global `max-min≤1e-6` rule만으로는 support-region plateau를 잡지 못함 |
| `top_score_tie_pixel_count`, `top_score_tie_fraction` | new: max score와 `1e-6` 이내인 pixel의 개수/전체 비율. 비율>`0.001`이면 top-score plateau로 보류 |
| `temporal_map_mae_to_previous`, `temporal_map_max_abs_to_previous` | new: selected endpoint 순서에서 이전 map과의 차이. 두 값이 모두 `≤1e-6`이면 temporally invariant로 보류 |
| `candidate_decoder_status` | expected: `withheld_top_score_plateau` 또는 `withheld_temporally_invariant_map`이며 count=0. support mask는 decoder 입력이 아님 |

## 7. 실행 원칙

* `processed/`는 재생성 가능한 결과이며 기본적으로 Git 추적 대상이 아니다. 다만 검토 근거를 보존하기 위해 11개 QC PNG 사본과 설명은 `docs/qc_images/`, `docs/quality-control-images.md`에 Git 추적한다.
* full-scale saturation `raw==65535`은 validity mask=0이다.
* target support 밖과 early XCT 미지원 layer는 negative/normal이 아니라 unknown이다.
* validation/test는 normalization·target scaling 통계에 사용하지 않는다.
* 새 코드가 추가되면 이 표에 실행 위치, 역할, 입력, 출력, 의존성을 추가한다.
